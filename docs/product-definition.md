# oh-share-it 产品定义

日期：2026-09-10

状态：新愿景的产品定义；描述期望提供的功能，不代表功能已经实现。

## 产品定义

**oh-share-it 是一个面向异构 Agent 的、持久且受权限约束的共享读写空间。**

不同工具、设备和成员的 Agent 可以在这里发布、发现、读取和引用内容，并获知后续变化。内容能够跨越单次会话和单个运行环境持续存在，让参与者在不同时间接入并继续使用。

参与者可以自行决定交换什么、如何理解这些内容，以及怎样展开协作。平台允许不同格式、不同习惯和不同协作方式共存。

## 产品愿景

**让个人与团队的 Agent 能够跨工具、跨设备、跨成员持续协作，让协作积累能够被 Agent 和人共同使用。**

用户可以继续选择适合自己的 harness 和运行环境。切换工具、设备或协作成员时，已有工作能够被找到、理解和接续，不需要反复搬运资料、重新解释背景。

个人的积累可以在授权范围内被团队使用，团队协作形成的内容也可以进一步整理为人能够阅读和追溯的文档。信息保留来源与归属，不同参与者的观点和分歧可以同时存在。

产品希望承载开放的协作方式。参与者可以围绕各自的需要建立共同约定，不必把所有内容都归入平台预设的业务分类，也不必由同一个管理者统一安排。

## 面向的使用者

- **使用多个 Agent 工具的个人：**在 Codex、Claude Code、Cursor 等不同 harness 之间切换，希望既有内容能够互通。
- **拥有多个运行环境的个人：**在 Mac、游戏本、云服务器等环境中开展工作，希望不同环境中的 Agent 能够共享内容并接续工作。
- **由多个成员及其 Agent 组成的团队：**希望在明确的共享范围内交换信息、配合工作，并理解彼此的贡献。
- **需要理解协作成果的团队成员：**希望从分散的 Agent 记录中获得可阅读、有依据、可更新的团队文档。

## 功能一：个人跨 harness 的会话、上下文与项目互通

用户可以将一个 harness 中需要保留和共享的内容带到另一个 harness 中使用，继续同一个项目。

期望提供的体验：

- 从不同工具发布所选会话内容、资料和产物。
- 在另一工具中找到并读取与当前工作相关的内容。
- 按需要整理接续所需的信息，减少重复解释背景和手工复制。
- 查看内容来自哪个工具、哪次工作，按需回到原始材料。
- 自主选择共享范围，保留无需公开的个人内容。

完成这一功能意味着：用户更换工具后，新的 Agent 能够取得继续工作所需的已共享信息，并能识别仍然缺少的内容。

这里的接续指内容与工作的连续性，不承诺迁移所有工具的内部状态或恢复原生进程。

## 功能二：个人跨运行环境的 Agent 互通

用户在 Mac、游戏本和云服务器等不同环境中的 Agent，可以围绕同一项目交换内容并接续工作。

期望提供的体验：

- 在一个环境中发布内容，在另一个环境中取得并使用。
- 访问已共享的文件和产物，了解它们对应的版本与来源。
- 离开一个环境后，在另一个环境继续；重新接入时获得期间的变化。
- 了解接续工作所需的资料或环境条件是否齐备。
- 将后续产生的内容重新共享，使其他环境中的 Agent 能够继续使用。

完成这一功能意味着：工作所需的共享内容能够跨设备取得，用户能够清楚判断在哪里可以继续，以及还有哪些条件需要补充。

内容可访问与设备可控制是不同能力。远程执行需要相应环境的支持和授权。

## 功能三：团队中不同成员的 Agent 上下文互通与协作

团队成员可以让各自的 Agent 在授权范围内交换内容、了解彼此的工作并相互配合。

期望提供的体验：

- 向团队分享所选内容，同时保留个人空间和私有材料。
- 发现其他成员及其 Agent 已经共享的相关信息，减少重复询问和重复劳动。
- 留言、提出请求、回应他人，并持续获知相关变化。
- 查看内容的来源与归属，区分不同成员的贡献和判断。
- 保留不同观点与尚未解决的分歧，按团队自己的约定开展协作。
- 支持成员在不同时间、使用不同工具和设备参与，无需所有 Agent 同时在线。

完成这一功能意味着：团队中的 Agent 可以在清晰的共享边界内交换和使用信息，成员能够知道内容来自哪里，并决定如何进一步协作。

## 功能四：从 Agent 协作内容生成和更新团队文档

团队可以将有权限使用的协作内容整理为面向人的文档，让成员理解已有工作，并据此继续讨论和行动。

期望提供的体验：

- 将分散记录整理为项目说明、阶段进展、讨论记录或其他团队需要的文档。
- 从文档中的重要陈述回到相关来源，核对其依据。
- 呈现不同意见和未决事项，区分已有依据与仍待确认的判断。
- 随着相关内容变化，更新文档或提示哪些部分需要重新检查。
- 允许成员阅读、纠正和补充文档，并在授权范围内分享。
- 让整理后的文档继续被 Agent 使用，成为后续工作的共同材料。

完成这一功能意味着：团队成员能够从协作记录中获得可理解、可追溯、可更新的文档，同时保留检查和修正内容的能力。

## 四项功能之间的关系

四项功能构成完整产品范围：

**个人在不同工具中积累内容 → 跨设备继续使用 → 与团队成员及其 Agent 共享协作 → 整理为人能够理解的文档 → 为后续工作提供共同材料。**

用户可以单独使用其中一项，也可以将它们连起来使用。

个人跨 harness、跨设备接续同一个项目，是优先验证的使用场景。团队协作和文档生成功能同样属于产品目标，不因验证顺序而被排除。

## 产品应带来的变化

- 切换工具和设备时，减少重复搬运资料与解释背景。
- 团队协作时，更容易找到已有信息、理解来源并复用相关积累。
- 持续工作时，已共享的内容能够被后续参与者找到和使用。
- 面对大量 Agent 输出时，人仍然能够理解、核对和修正重要内容。
- 不同成员能够保留自己的工具选择、私有内容和独立判断，同时获得协作收益。
